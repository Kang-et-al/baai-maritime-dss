# 팀 공유 초안 v0.2.0-draft.1

기존 개인 실험 폴더와 분리한 팀 공유용 Python 환경입니다.
GitHub 저장소 복제 → Python 3.12 설치 → setup_windows.bat 실행으로 시작합니다.
Mac/Linux 설치 명령과 AI용 시작 요청문도 README에서 연결합니다.

## 포함 내용

- 기존 격자·DP·3시간 롤링·9개 태풍 시나리오 보존.
- mean-CVaR 평가: λ=0.5, α=0.8. 정본 configs/baseline.json.
- 완주 재생/단계별 실시간 대시보드, 시간 슬라이더, PNG·CSV.
- Python 3.12.x / NumPy 2.3.5 / Pillow 12.3.0 기준 설치.
- Git 커밋·변경 여부·설정/코드 해시·실행 환경 자동 기록.
- AGENTS.md / CLAUDE.md / 팀 운영·AI 사용·실험 등록 안내.
- 기준 태그 원본 검증과 일반 개발 검증 분리.
- 한글 글꼴과 공개 라이선스 포함. 별도 기상/AI API 키와 솔버 불필요.
- Actions는 수동 실행만 제공. 계산은 로컬 PC에서 수행.

검증 범위: Windows의 새 가상환경 설치·21개 단위/회귀검증·전체 항해·복제본 첫 스텝.
Mac/Linux 실행은 아직 직접 확인하지 않았습니다. 수동 workflow에 Windows/Linux 검증을 준비했습니다.
