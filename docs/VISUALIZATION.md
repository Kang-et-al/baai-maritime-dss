# 시간 탐색 및 실험 형식

## 두 실행 형식

완주 재생 실험은 `--experiment replay`. 모든 롤링 결정을 실행한 후 0시간부터 마지막 상태까지 시간 탐색기를 생성한다. 성공이면 홍콩 도착, 실패면 실제 종료 상태를 명확히 표시한다.

단계별 실시간 실험은 `--experiment live --steps N`. 각 스텝의 JSON/그림/대시보드를 저장한다. 최신 상태를 보고 있을 때만 5초 주기 새로고침을 적용한다. 과거를 탐색하면 자동 새로고침을 보류한다. 새 스텝을 계산하는 주체는 Python이며 브라우저는 저장된 결과를 보여준다. 실제 시간과 모의시간은 구분한다.

Python에서는 `Simulation.run(..., experiment_format='replay' 또는 'live')`로 지정한다. `presentation.json`은 표시 형식이며 수치 모델 설정과 분리되어 있다.

## 데이터 경계와 시점

`replay.build_payload`는 완료 스텝 JSON에서 현재 시점의 `state_before`, 관측 현재 태풍, 그때 발행된 예측, 첫 실행계획과 시나리오별 조건부 미래계획을 추출한다. 최종 `state_after`를 마지막 프레임으로 붙인다.

실제 항적 데이터는 완료된 모든 이동을 보관하지만 화면에는 선택한 시간 이전에 완료된 행동만 그린다. 이후 실제 항적과 숨겨진 실제 태풍 미래는 보여주지 않는다. 계획과 예측에는 당시 알려진 앞으로 3시간의 기상이 포함될 수 있다(기존 모델 가정).

진행 중의 맨 마지막 상태에는 다음 재연산 결과가 아직 없으므로 최근 발행된 예측임을 표시한다. 완료 상태에서는 미래계획을 지운다.

## 기상과 반경

기본 실험: R=200km, cutoff=600km. 이번 교차 실험: R(I)=280I km, cutoff(I)=840I km, 최대파고 10I m. `radius_scales_with_intensity` 플래그로 선택한다. I=0에서는 파고가 0이고 영향권이 없다.

H(d)=peak*exp(-(d/R)^2)인 파고장에서 높이 h의 등고선 반경은 min(cutoff,R*sqrt(log(peak/h)))이다. peak<=h이면 표시하지 않는다. 시각화만 반경을 바꾸지 않고 최적화·실제 실행·PNG·시간 탐색기에 같은 규칙을 적용한다.

예측은 3경로의 기준 강도 시나리오를 바탕으로 12시간 간격 영향권을 그린다. 전체 9개 미래 선박경로는 유지하고 기준 시나리오는 더 진하게 그린다. 그림이 실제 기상예측의 신뢰구간이라는 의미는 없다.

## 구현 구조

- `report.render_step`: 기존 PNG와 KPI, 속도별 실선/점선, 실제·예측 영향권.
- `report.render_archive`: 기존 스텝별 그림·JSON·CSV 링크 모음.
- `replay.build_payload`: 파일만 읽어 브라우저용 데이터 생성.
- `replay.export_replay`: 오프라인 HTML 생성, 선택적으로 대화용 축약 화면 생성.
- `assets/replay.html`: 외부 API 없이 지도·시간 선택·자동재생·KPI 갱신.

지도는 기존 Natural Earth 기반 투영 육지를 그대로 사용한다. 대화 안에서는 d3-geo identity로 이미 투영된 좌표를 화면에 매핑하고, 오프라인 HTML에서는 같은 선형 매핑을 직접 적용한다.
