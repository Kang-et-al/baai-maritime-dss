## 1. 후보 노드 평가 목적함수

각 롤링 회차에서 후보 j의 평가값은 다음과 같다.

\[
F_k(j)=C_k(j)+(1-\lambda)\sum_{\omega\in\Omega_k}p_\omega Q_k^\omega(j)
+\lambda\operatorname{CVaR}_{\alpha}\!\left(Q_k^\omega(j)\right),\qquad
j_k^*\in\arg\min_j F_k(j).
\]

- C는 현재부터 정확히 3시간 후 후보 j까지의 최소 실행비용이다.
- Q는 기존 시나리오별 후방 DP로 구한, j에서 홍콩까지의 최소 잔여비용이다. 연료·시간·지연비용을 포함한다.
- CVaR는 **비용이 큰 쪽**의 꼬리를 평가한다. 별도의 파고 위험점수에 CVaR를 적용하는 것이 아니다.
- 기본값은 `risk.lambda=0.5`, `risk.alpha=0.8`이다. 미지정 값을 실행 가능한 공유 기본값으로 정했으며 경험적으로 추정한 위험선호는 아니다.
- λ=0이면 기존 평균 기준, λ=1이면 미래 CVaR 기준이다. α는 0 이상 1 미만이며 α=0일 때 CVaR는 평균과 같다.

동일 후보의 C는 모든 시나리오에서 같은 확정비용이다. CVaR의 평행이동 성질 때문에 C를 한 번 더하지 않고 위처럼 한 번만 더한다. 전체 잔여비용 C+Q에 mean-CVaR를 적용해도 같은 값이다.

### 시나리오별 기존 최적경로를 유지해도 되는 이유

현재의 2단계 경로는 시나리오 간 공유 제약 없이 각각 계산한다. 각 시나리오 비용을 최소화한 Q*는 다른 허용 경로 비용보다 성분별로 작거나 같다. 평균과 상위 비용 CVaR는 모두 비용이 증가하면 감소하지 않으므로, 0≤λ≤1에서 Q*를 고정해 종합 평가해도 이 2단계 모형의 목적에 맞는다. 따라서 후방 DP, 1단계 실행비용, 경로 복원 알고리즘을 바꾸지 않고 **후보별 집계·선택 단계**만 확장했다.

기존 DP가 지배적인 연산이다. 추가 집계는 후보마다 시나리오 비용 9개를 정렬하는 O(S log S)이며 새 솔버가 필요 없다. 향후 시나리오 간 경로를 묶는 제약이나 별도의 위험 노출 상태를 도입하면 이 분리 구조를 재검토한다.

### 이산 CVaR의 정확한 계산

\[
\operatorname{CVaR}_{\alpha}(Q)
=\min_{\eta\in\mathbb R}\left[\eta+
\frac{1}{1-\alpha}\sum_\omega p_\omega\max(Q_\omega-\eta,0)\right].
\]

구현은 같은 식에 해당하는 상위 (1-α) 확률질량의 가중평균을 쓴다. 꼬리 경계에 걸리는 시나리오는 확률 일부만 포함한다. 단순히 `비용≥VaR`인 시나리오 전체를 평균내지 않는다.

9개 균등확률에서 α=0.8이면 가장 비싼 비용의 5/9와 두 번째 비용의 4/9를 가중평균한다. α≥8/9에서는 꼬리가 최악 시나리오 하나 안에 들어가 CVaR가 최악 비용과 같아진다. 이 때문에 초기 기본값을 0.8로 두었다.

양의 확률 시나리오 중 하나라도 경로가 없으면 기존대로 해당 후보를 불가능으로 처리한다. λ=0 또는 1에서도 `0 × infinity`가 NaN을 만들지 않는다. 3시간 내 조기도착 후보의 미래비용은 0이며 실제 도착시점까지의 비용·지연비용으로 평가한다.

이 위험평가는 각 재연산 회차의 후보에 적용한다. 실제 누적 비용을 위험가중 비용으로 바꾸거나 항해 전체의 nested CVaR를 계산하는 것은 아니다.

## 2. 고정한 시나리오 생성기

식별자: `trend-path-intensity-3x3-v1`. 직전 `crossing_replay` 실험의 수식·로직·파라미터를 그대로 유지한다.

- 실제 태풍 하나를 시간표로 고정하고, 공개 구간을 따라 순차적으로 드러낸다.
- 첫 3시간 공통 기상, 그 뒤 좌/기준/우 경로 × 약/기준/강 강도, 총 9개 균등 시나리오.
- 중심경로: 공개된 3시간 속도를 48시간 감쇠 외삽. 중심강도: 12시간 추세 외삽, 24시간 이후 48시간 척도로 약화.
- 경로 편차: 24시간에 최대 100km. 강도 편차: 12시간에 최대 0.15. 분기 시점 편차는 0.
- 매 3시간 새 공개구간으로 예측 전체를 재생성하며 숨겨진 실제 미래 경유점을 읽지 않는다.
- 상세 공식은 `weather.py`와 기존 `docs/MODEL_SPEC.md`의 생성식에 있다. 모델 문서의 이전 고정 반경 예시는 아래 공유 설정으로 대체한다.

이전 결과의 0h·21h·33h 예측에서 추출한 회귀 기준값을 `tests/fixtures/crossing_forecast_v1.json`에 보관한다. 전체 실험을 재실행하지 않고 생성기가 같은 예측을 내는지 검사할 수 있다.

## 4. 고정한 시각화·결과 보고

- **완주 재생 실험**: 도착까지 실행 후 시간 슬라이더로 탐색.
- **단계별 실시간 실험**: 지정 스텝 실행, 저장·이어하기, 최신 대시보드 갱신.
- 기존 위치 표식·속도별 색·실제/미래 항로·현재/예측 파고 영역·지도 범위를 유지한다.
- `dashboard.html`, `archive.html`, `figures/step_*.png`, `summary.csv`, `steps/step_*.json`, `state.json`, `manifest.json`을 유지한다.
- 새 위험평가를 표현할 때만 mean, CVaR, λ, α, 통합 평가값을 추가한다. actual cost는 실제 비용 그대로다.

| 저장 필드 | 의미 |
|---|---|
| `first_cost_usd` | 후보의 C (후보 행) |
| `mean_remaining_usd` | 시나리오 Q의 평균 |
| `cvar_remaining_usd` | 시나리오 Q의 CVaR |
| `risk_adjusted_remaining_usd` | (1-λ)mean + λCVaR |
| `expected_total_usd` | C + mean. 기존 필드 이름의 의미 유지 |
| `objective_total_usd` | C + (1-λ)mean + λCVaR. 실제 후보 선택 기준 |
| `cvar_tail_weights` | 원래 시나리오 순서에 맞춘 꼬리 내 정규화 가중치 |

이전 저장 결과는 평균 기준의 역사적 결과로 보존한다. 재렌더링 시 위험 필드가 없으면 기존 평균 라벨을 사용하며 새 CVaR 결과로 재해석하지 않는다. 기존 결과·보고서·발표자료는 이번 목적함수 확장 이전 자료다.

## 5. 공통 기준 확인

```powershell
python -m maritime_sim baseline
python -m unittest discover -s tests -v
```

첫 명령은 실험을 실행하지 않고 `configs/baseline.lock.json`의 코드·격자·설정·시각화 해시를 확인한다. 파일을 바꾸면 `changed`를 반환한다. 팀 합의로 기준을 바꾸는 경우 새 baseline 버전을 부여한 뒤 lock을 갱신한다. 비교 실험의 별도 설정은 결과 폴더에 전체 설정과 해시로 구분한다.

이 문서의 수식·생성 규칙이 공유 기준이다. 팀 공유 배포 및 새 mean-CVaR 완주 결과의 진행 상태는 PROJECT_CONTEXT_TEAM.md와 results/index.csv를 따른다. 과거 개인 단계의 실행 상태와 구분한다.
