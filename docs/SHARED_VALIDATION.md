## 범위와 후속 작업

Mac/Linux는 안내와 수동 검증 workflow를 제공했으나 아직 해당 운영체제에서 실행하지 않았다.
팀원 본인의 PC 설치·수정 브랜치 Push 확인은 초대 수락 이후 수행한다.
GitHub Actions는 자동으로 실행하지 않는다. 무료 실행량을 확인하고 필요 시 수동 실행한다.
완주 실제 비용과 매 시점의 위험 조정 목적함수 점수는 다르므로 구분해서 해석한다.
