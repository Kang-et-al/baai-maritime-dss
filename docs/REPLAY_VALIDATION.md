# 시간 탐색·태풍 교차 실험 검증 (2026-10-11)

## 수치 실행

- 설정: `configs/korea_china_crossing.json`.
- 출력: `outputs/crossing_replay`.
- 완료: 44스텝, 출항 후 132시간, 홍콩 N642 도착.
- 이동 1,584nm, 대기 2시간, 연료 76.20571t, 총비용 111,723.43 USD, 지연비용 0.
- 실제 이동 아크 실효속도: 6kn 1개, 9kn 2개, 약 10.29kn 1개, 12kn 74개, 14.4kn 1개, 18kn 9개.
- 저장된 평온 결과와 비교해 4~24번째 스텝의 위치가 다르다. 출항 9시간 이후 서쪽 우회를 선택했고 21~30시간에는 쾌속으로 이동했다. 이것은 태풍에 대한 반응 확인이며 알고리즘 성능 비교 실험이 아니다.

실제 실행 전후 상태의 연결, 행동별 연료·비용 합계, 도착 상태, 현재 코드·설정·네트워크 해시가 manifest와 일치하는지 확인했다.

## 시각화·정보 경계

- 의사결정 직전 상태 44개와 최종 도착 상태 1개, 총 45개 시점.
- 시간 탐색기의 최초/다음/마지막 선택, KPI 갱신, 다시 그리기 동작을 JavaScript DOM·Canvas 모형으로 검증했다.
- 초기 프레임은 실제 미래 항적을 표시하지 않으며, 도착 프레임에는 미래 선박계획을 표시하지 않는다.
- 현재 태풍·예측 영향권은 같은 파고 함수의 등고선 반경을 사용한다. 강도 비례 반경과 파고 경계값 일치를 검증했다.
- 실제 PNG를 열어 부산/홍콩 육지 위 라벨, 출발/도착/현재/이전 표식, 속도별 항적과 예측 영향권을 확인했다.
- 브라우저 자동 화면 확인은 로컬 미리보기 연결 시간초과로 완료하지 못했다. HTML/JavaScript 동작 모형 검사와 PNG 육안 확인을 수행했으며 실제 브라우저 검증으로 표현하지 않는다.
- 대화용 화면은 1MB 미만으로 저장했다. 오프라인 보고서는 외부 자원이나 API 없이 작동한다.

## 실시간 형식
