# 기존 baseline과 확장판의 핵심 차이

비교 기준은 공유 태그 **v0.2.0-draft.1**, 확장판은 **v0.3.0-draft.1 후보(미게시)**다. 이전 격자 실험·중간 속도상한 육각 모델·현재 추진 반응 모델은 서로 다른 버전이다.

| 항목 | 기존 공유 사각 baseline | 이번 확장판 |
|---|---|---|
| 공간과 이동 | 사각망, 직교 방향 중심 | 중심 간격18nm 육각망, 6방향 및 곡선 primitive, 홍콩 정확 좌표 연결 |
| 실제 상태 | 노드 중심 이산 운항 | 연속 좌표·시각·실제 속도·방향 |
| 초기 의사결정 | 다음 구간의 목표 노드 중심 | 목표 노드·곡선·추진명령·도착 정지 여부의 유한 계획 선택 |
| 속도 | 운항 모드와 기상계수로 산정 | 명령 q와 실제 v 분리, 파고 저항에 따른 점진적 가감속·정체·회복 |
| 파고 영향 | 단계적 감속·강한 파고 이동 금지 | 파고별 별도 금지 제거, κH² 저항; 단12h 전이 완료 조건은 유지 |
| 선회 | 별도 방향·관성 상태 없음 | 방향6×속도4 DP 상태, Bézier 연결, 반경·선회율·선회 속도 제약 |
| 연료 | 모드/속도 기반 비용 | 적용 추진명령의 세제곱률+양의 속도제곱 증가 보정; 감속 할증 없음 |
| 정보 시점 | 다음3h 실제 기상을 공개한 기존 실험 구조 | 현재까지 최근 최대3h 관측만 사용; 실제 미래는 World 내부 |
| 시나리오 | 3경로×3강도 추세·편차·감쇠 | 같은 실제 태풍 waypoint/함수 계열 유지, 관측 시점에서 새3×3 생성 |
| 위험 목적 | 공유 기준 λ=.5, α=.8 | 총비용 mean–CVaR 유지, 사용자 지정 기본 λ=0, α=.8 |
| 장기 평가 | 노드·시간 중심 DP | 시간×노드×방향×실제 속도, 시간/속도 가치 보간 |
| 기본 계산 | 기존 사각 DP | M=1: 전체 육각 DP 내부 병렬; M≥2: 선택적 육각 DP 시나리오 병렬 |
| 갱신/긴급 | 고정 주기 중심 | 최대3h 재계획 및 임의 상태 스냅샷 입력; 표준 완주 실험은 고정3h |
| 기록·시각화 | 시점별 대시보드·재생 | 추진/실제 속도·가감속 상태, 파고 영향 경계, 후보별 비용·알고리즘 계측 |

## 유지한 의사결정 골격

공통 초기 후보 → 시나리오별 장기 잔여비용 → 총비용 평균/위험 집계 → 실제 환경에서 일부 실행 → 관측 후 재계획이라는 구조다. CPLEX/MILP로 바꾼 것이 아니며 선택적 DP는 물리 모형을 바꾸는 해법이 아니다.

## 이번에 추가 확정한 코드와 보존한 코드

- `hex_dss/`, 기존 `configs/`, `data/`, `experimental_dp/voyage.py`, 두 선택적 커널은 이번 확정 작업에서 수정하지 않았다.
- 새 `experimental_dp.experiment`가 문제 유형별 기본 실행을 담당한다. 기존 전체/선택적 전용 실행기는 남긴다.
- 설정 `configs/hex_propulsion.json`의 `compute_limit_s=600`은 일부 과거 CLI용이다. 새 기본 실행기는 이를 시간제한으로 사용하지 않는다. 물리·계획기간 제한과 구분한다.
- 기존 완주 결과의 소스 해시·설정은 변경하지 않는다. 자동 선택 실행기의 새 성능 실험으로 재명명하지 않는다.

## 비교 해석 시 주의

사각→육각의 차이는 격자 모양만의 효과가 아니다. 정보공개 가정, 추진·기상 제약, 상태 차원, 비용, 위험 가중치가 함께 달라졌다. 따라서 경로 차이를 “육각화 효과” 또는 “선택적 DP 효과”로만 설명하지 않는다. 기존 사각 실험 중 일부는 mean–CVaR 도입 전 설정이므로 초기 사례의 회피를 CVaR 효과로 단정하지 않는다.

새 완주 비교에서 태풍은 큰 우회보다 높은 추진·속도 변화·대기로 대응했고, 무태풍 대비 연료36.7%, 비용11.7%가 증가했다. 이 거동은 현재 비용/저항 함수의 결과이며 모든 현실 해역에서 바람직한 운항이라는 의미는 아니다.

기존 태그·Release·baseline.lock은 유지한다. 확장판의 기본 모델 승격이나 기존 저장소 main 변경은 별도 공유/검토 단계다.
