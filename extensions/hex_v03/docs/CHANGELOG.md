## 이 후보 이전의 로컬 개발

선택적 DP의 작은 문제 및 t=3h 값 일치, 동일 병렬 조건 시간 비교, 태풍/무태풍 선택적 전용 완주, 거동/성능 한계 분석을 완료했다. 실행 결과는 당시 소스 해시와 함께 보존하며 이번 자동 선택 실행기 실측으로 변경하지 않는다.
