# 선택적 DP 태풍·무태풍 완주 비교

두 실험 모두 새 선택적 DP로 출항부터 도착까지 계산했다. 3시간마다 관측·시나리오를 갱신했으며, 마지막 도착 구간만 3시간보다 짧을 수 있다. 기존 전체DP·기존 무태풍 결과를 계산에 재사용하지 않았다. 태풍9개 시나리오를 공유메모리 최대9스레드로 평가하고, 무태풍의 동일9개 시나리오는 새로운 선택적 DP1회 결과를 공유했다.

| KPI | 무태풍 | 태풍 | 태풍−무태풍 |
|---|---:|---:|---:|
| 도착시간(h) | 109.591 | 107.027 | -2.564 |
| 거리(nm) | 1,259.198 | 1,251.874 | -7.324 |
| 연료(t) | 51.385 | 70.218 | +18.833 |
| 총비용($) | 85,626.449 | 95,644.218 | +10,017.769 |
| 최대 파고(m) | 0.000 | 5.801 | +5.801 |

태풍 결정수 36, 무태풍 결정수 37. 지연비는 각각 $0.00, $0.00다. 태풍의2/4/6m 이상 노출시간은 {'2': 11.112401056220747, '4': 6.245373380632518, '6': 0.0}h, 거의 정체한 시간(실제속도0.1kn 미만)은 1.611h다. 이는 전복이나 안전확률 판정이 아니다.

선택 추진명령 횟수: 태풍 {'0': 0, '6': 0, '12': 29, '18': 7}, 무태풍 {'0': 0, '6': 0, '12': 36, '18': 1}. 추진명령은 실제속도와 다르며, 파고·선회·제동으로 실제속도가 변한다. 도착·시간연결·연료/비용 합계·가감속 한계를 검사했다. 가감속 검사는 기존 종단 정지의1e-4kn 미만 잔차를0으로 맞추는 규칙을 명시적으로 포함한다. 태풍의 해당 종단 표본은 2개이며 최대 속도 잔차는 0.00004501kn이다. 결과·운동식을 수정하지 않았고 나머지 증분은24kn/h 이내다. 상세 표본은 comparison.json에 보존했다. 실제 표본 항적의 육지 완충구역 교차 여부: 태풍 False, 무태풍 False.

실행 기록상 대기는 태풍 1.568h, 무태풍 0.000h다. 이는 초기 연결 후 같은3시간 구간 안에서 중앙 참고경로의 대기를 실행한 것까지 포함한다. 따라서 첫 단계 대기 후보 선택 횟수0을 실제 대기가 없었다는 뜻으로 해석하지 않는다.

기록된 의사결정 시간 합계는 태풍 6388.9s, 무태풍 4689.1s이고, 최대는 312.0s / 157.2s다. 스레드 전환 시 중단·재개 전의 벽시계 시간은 일부 결정의 solve_seconds에 합산되지 않으므로 이 합계를 실험 전체 활동시간으로 해석하지 않는다.

현재는 유한 후보·시간/속도 보간DP와 연속 참고경로 재검증을 결합한 오프라인 모의실험이다. 연속 전역 최적성·실선 적합성·해난 안전성을 검증한 것은 아니다. 원래 baseline과 이전 연산 방식, 기존 결과는 보존하고 GitHub에는 업로드하지 않았다.

시점별 관찰은 각 실험의 dashboard.html을, 실제 항적 비교는 비교 폴더의 comparison.html을 사용한다.

## 실제 파고 저항의 실행 사례

출항 후 31.283h, 실제 파고 5.801m에서 적용 추진 수준은 18.0kn 상당, 실제 속도는 4.181kn이었다. 추진 명령과 실제 속도를 분리한 운동 모형의 실행 기록이다. 별도 파고별 속도상한이나 통과금지를 적용한 결과가 아니다.

실제 고추진(17.9kn 상당 이상) 적용시간은 태풍 16.208h, 무태풍 0.279h다. 태풍의 고추진·실제6kn 미만·파고4m 이상이 동시에 기록된 시간은 2.742h다. 결정시점의 명령 횟수와 실제 적용시간은 구분한다.
