# t=3h 요청 기반·상하한 결합 DP 비교 결과

## 결론

모델·설정·초기 상태·태풍 시나리오·적분 간격을 유지했다. 선택 후보2 / 노드2290 / 추진12kn 상당, 목적값 **$84,348.03761768**. 기존 36후보×9시나리오의 유한/불가능 판정이 일치했다. 유한 잔여가치 최대차이 7.28e-11달러. 동일 병렬 조건 대조와의 최대차이 7.28e-11달러.

epsilon=0.01달러를 설정했으나 근사 조기 종료에는 사용하지 않았다. 모든 후보의 요청된 가치를 확정했으며, 로컬 상한보다 보수적인 하한이 큰 행동만 제외했다. 현재 유한 행동·보간 DP 기준의 값 일치이며 연속 전역 최적성 인증이 아니다.

## 시간: 병렬 구조를 구분해야 함

| 항목 | 초 |
|---|---:|
| 이전 정본 활동시간(중단·재시작 검증 포함) | 771.52 |
| 새 엔진 전체 경과시간 | 525.17 |
| 같은3프로세스×1스레드 기존 전체DP 전체 경과시간 | 859.53 |
| 새 엔진 DP 작업시간 합(병렬 작업 합산) | 1334.40 |
| 같은 병렬 조건 기존 전체DP 작업시간 합 | 2097.44 |
| 새 엔진 체크포인트 기록 합 | 6.78 |

이전 정본은 시나리오 순차/상태내부8스레드, 새 엔진 및 동일조건 대조는 시나리오3프로세스/각1스레드다. 새 엔진의 이전 정본 대비 경과시간 감소 31.93%를 전부 선택적 계산의 알고리즘 효과로 해석하면 안 된다. 동일조건 대조 대비 경과시간 감소율은 38.90%(음수면 새 방식이 더 느림)다.

동일조건 전체DP 대조는 큰 가치표 파일을 저장하지 않아 새 엔진에 약6.8초의 기록 부담이 더 있다. 기존 정본 전체시간에는 연속 참고경로 복원도 포함되며 새 엔진은 이를 실행하지 않았다. DP 작업시간 합과 계산량을 함께 비교한다. 메모리는 프로세스별 가치표·격자를 가지므로 증가하며, 프로세스 전체 최대 메모리는 이번에 별도 계측하지 않았다.

새 엔진 확정 상태 250,099,054개(9시나리오 합), 적분 전 제외 730,944, 적분 후 후속 계산 제외 1,958,243,861. 적분 전 하한은 약하여 대부분의 절감은 후속 상태 전개 생략에서 발생했다. 요청 기반 탐색은 많은 상태를 여전히 방문하며, 불규칙 메모리 접근·프레임/가지치기 관리 때문에 계산량 감소가 곧 시간 감소로 이어지지는 않는다.

## 검증·보존

- 기존32개 테스트 통과. 새4개 테스트에서 4개 무작위 작은 DAG, 시간/속도 보간·대기·지연·불가능 상태·경계값·직접 적분을 검사했다. 가지치기 활성/비활성 모두 전체 DP 값과 일치.
- 이전 모델 파일과 소스 해시, 입력 설정·상태 동일성 검사 통과.
- 과거 가치표는 새 계산에 사용하지 않았다. 이전 결과와 동일조건 대조는 계산 완료 후 비교에만 사용했다.
- 실제 배 이동 및 새 연속 참고경로 복원은 하지 않았다. 전체 항해·긴급 실행 검증을 완료했다고 해석하지 않는다.
- 원래 baseline, 이전 육각 전체DP, 기존 outputs 보존. GitHub 업로드 없음.

알고리즘과 실행법은 [SELECTIVE_DP.md](SELECTIVE_DP.md), 수치는 `outputs/t3_selective_v1/result.json`, `verification.json`, 각 시나리오 파일에 있다. 기존 전체DP는 기본 비교 기준으로 남겨두고, 이번 엔진은 별도 실험용으로 유지한다.
